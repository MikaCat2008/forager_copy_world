# Forager Copy World

## О проекте

Это не просто копия Forager — это мой амбициозный шаг вперед в мире инди-игр. Я беру проверенную формулу пиксельного экшена с элементами выживания и рогалика, но добавляю туда мультиплеер, который заставит вас пересмотреть, что такое онлайн-игры. Проект построен на современной архитектуре ECS, с сервером, который выдержит сотни игроков, и клиентом, который летает на 120 FPS. Я не боюсь вызовов — я их создаю.

## Ключевые особенности

- **Мультиплеер без компромиссов**: Полноценный сервер-клиент, где каждый игрок живет в одном мире. Синхронизация позиций, инвентарей, структур — все в реальном времени. Забудьте о лаге, я оптимизировал под скорость света.
  
- **ECS-архитектура**: Сущности, компоненты, системы — это не buzzword, это мое оружие. Масштабируемость на уровне AAA-проектов, но в пиксельном стиле. Добавляй новые фичи без переписывания кода — я так и делаю.

- **Чанковая генерация мира**: Мир бесконечен, но умный. Чанки генерируются на лету с многопроцессорностью, чтобы ваш процессор не скучал. Процедурная генерация, которая создает уникальные биомы и структуры.

- **Геймплей на стероидах**: Исследуй, строй, крафти, сражайся. Инвентарь с сотнями предметов, система крафта, разрушаемые структуры. Игрок — не просто спрайт, а полноценный контроллер с сетевой синхронизацией.

- **Современный стек**: Pygame-CE для графики, многопоточность для производительности, чистый Python без лишнего мусора. Код структурирован так, что даже новичок поймет, а профи оценит.

## Архитектура

Проект разделен на модули, каждый из которых — шедевр инженерного искусства:

- **kit/**: Мой собственный фреймворк. Графика, ввод, сцены, ECS-компоненты — все тут. Переиспользуй в своих проектах, я не жадный.

- **network/**: Сервер и клиент на сокетах. Модели данных, методы, обновления — чистая абстракция для масштабирования.

- **scenes/**: Игровые сцены. Пока одна, но архитектура позволяет добавить меню, лобби, что угодно.

- **world.py, player.py, inventory.py, crafting.py**: Ядро геймплея. Мир с чанками, игрок с контроллером, инвентарь с сетевой синхронизацией.

Я использую многопроцессорность для тяжелых задач, как генерация мира, чтобы UI никогда не зависал. Потоки для сетевых запросов — асинхронность без asyncio, просто и эффективно.

## Почему это круто

Этот проект — доказательство, что один разработчик может создать мультиплеерную игру уровня indie-гигантов. Я не копирую слепо — я улучшаю. Forager был хорош, но без мультиплеера? Серьезно? Я добавил его, и теперь это платформа для экспериментов.

Масштабируемость: ECS позволяет добавлять новые сущности, компоненты, системы без боли. Хочешь добавить AI-врагов? Легко. Мультиплеерные бои? Уже в планах.

Производительность: 120 FPS на клиенте, сервер обрабатывает сотни обновлений в секунду. Многопроцессорность для генерации — ваш ПК будет работать на полную.

Код: Чистый, документированный, модульный. Не как в тех проектах, где все в одном файле. Я пишу код, которым горжусь.

## Запуск

### Сервер
Запусти `server.bat` или `python server.py`. Сервер слушает на порту 8080.

### Клиент
Запусти `client.bat` или `python client.py`. Подключайся к localhost.

### Основное приложение
`python main.py` — для локального тестирования без сети.

Требования: Python 3.8+, pygame-ce, установи зависимости из requirements.txt (если есть).
